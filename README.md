# Learn Playwright

A hands-on learning repository for JavaScript and Playwright fundamentals.
The examples are kept small and runnable so each lesson can be studied
independently.

## Prerequisites

- Node.js installed and available as `node`
- A code editor such as Visual Studio Code

## Repository Structure

```text
chapter_01_Basics/
  JavaScript basics, setup verification, and simple functions

chapter_02_Javascript_Concepts/
  Variables and introductory JavaScript concepts

chapter_03_Identifier_Literals/
  Identifier rules, naming conventions, comments, and Markdown notes

javascript-identifier-examples.js
  Additional valid and invalid identifier examples
```

## Running Examples

Run any JavaScript lesson from the repository root:

```bash
node chapter_01_Basics/01_Basics.js
node chapter_01_Basics/03_JS_VerifySetup.js
node chapter_02_Javascript_Concepts/05_JS_Basics.js
node chapter_03_Identifier_Literals/06_Identifier_Rules.js
```

Some examples intentionally contain large loops for practice. Run those
files only when you want to observe their output and execution behavior.

## Learning Notes

The Markdown files in `chapter_03_Identifier_Literals/` include explanations
of Markdown and useful Visual Studio Code shortcuts for macOS and Windows.
