# VS Code Keyboard Shortcuts - Mac

## General

| Shortcut | Action |
|----------|--------|
| `Shift + Cmd + P`, `F1` | Show Command Palette |
| `Cmd + P` | Quick Open, Go to File |
| `Shift + Cmd + N` | New window/instance |
| `Shift + Cmd + W` | Close window/instance |
| `Cmd + ,` | User Settings |
| `Cmd + K Cmd + S` | Keyboard Shortcuts |

## Basic Editing

| Shortcut | Action |
|----------|--------|
| `Cmd + X` | Cut line (empty selection) |
| `Cmd + C` | Copy line (empty selection) |
| `Shift + Cmd + K` | Delete line |
| `Cmd + Enter` | Insert line below |
| `Shift + Cmd + Enter` | Insert line above |
| `Shift + Cmd + \` | Jump to matching bracket |
| `Cmd + ]` / `[` | Indent/outdent line |
| `Cmd + Left` | Go to beginning of line |
| `Cmd + Right` | Go to end of line |
| `Cmd + Up` | Go to beginning of file |
| `Cmd + Down` | Go to end of file |
| `Ctrl + PgUp` | Scroll line up |
| `Ctrl + PgDn` | Scroll line down |
| `Cmd + PgUp` | Scroll page up |
| `Cmd + PgDn` | Scroll page down |
| `Opt + Shift + [` | Fold (collapse) region |
| `Opt + Shift + ]` | Unfold (uncollapse) region |
| `Cmd + K Opt + [` | Fold (collapse) all subregions |
| `Cmd + K Opt + ]` | Unfold (uncollapse) all subregions |
| `Cmd + K Cmd + [` | Fold (collapse) all regions |
| `Cmd + K Cmd + ]` | Unfold (uncollapse) all regions |
| `Cmd + K Cmd + C` | Add line comment |
| `Cmd + K Cmd + U` | Remove line comment |
| `Cmd + /` | Toggle line comment |
| `Shift + Opt + A` | Toggle block comment |
| `Cmd + F` | Find |
| `Cmd + H` | Replace |
| `Cmd + G` / `Shift + Cmd + G` | Find next/previous |
| `Opt + Enter` | Select all occurences of Find match |
| `Cmd + D` | Add selection to next Find match |
| `Cmd + K Cmd + D` | Move last selection to next Find match |
| `Opt + Click` | Insert cursor |
| `Opt + Cmd + Up/Down` | Insert cursor above/below |
| `Cmd + U` | Undo last cursor operation |
| `Shift + Opt + I` | Insert cursor at end of each line selected |
| `Cmd + I` | Select current line |
| `Shift + Cmd + L` | Select all occurrences of current selection |
| `Shift + Cmd + F2` | Select all occurrences of current word |
| `Ctrl + Shift + Cmd + Right` | Expand selection |
| `Ctrl + Shift + Cmd + Left` | Shrink selection |
| `Shift + Opt + (drag mouse)` | Column (box) selection |
| `Shift + Opt + Cmd + (arrow key)` | Column (box) selection |
| `Shift + Opt + Cmd + PgUp/PgDn` | Column (box) selection page up/down |
| `Shift + Opt + Up/Down` | Copy line up/down |
| `Opt + Up/Down` | Move line up/down |
